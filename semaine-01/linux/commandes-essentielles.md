# Commandes Linux essentielles — DevOps

## Navigation
- `pwd` → affiche le répertoire courant
- `ls -la` → liste tous les fichiers avec détails
- `cd ~` → retour au home

## Fichiers
- `touch fichier` → crée un fichier vide
- `mkdir -p dossier` → crée un dossier
- `rm -rf dossier` → supprime (dangereux)

## Système
- `whoami` → utilisateur courant
- `uname -a` → infos système
- `df -h` → espace disque
- `free -h` → mémoire RAM
